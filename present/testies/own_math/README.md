# own_math — свои математические функции

Побочный квест к circuitC: понять, как компьютер считает `exp`, `log`, `pow`,
написав их самому. Компьютер умеет только + − × ÷ — всё остальное собирается
из них. Каждая функция сверяется с настоящей `<math.h>`: максимальная ошибка
на наборе тестовых значений.

Порядок важен: каждая следующая функция использует предыдущие.

| # | Файл | Приём | Что узнаем |
|---|---|---|---|
| 01 | `sqrt_newton.c` | Ньютон: `y = (y + a/y)/2` | корни через итерации; дробная степень = корень |
| 02 | `own_exp.c` | ряд Тейлора + сужение диапазона | как считается e^x одними умножениями |
| 03 | `own_log.c` | мантисса×2^степень + ряд atanh | логарифм использует представление double |
| 04 | `own_pow.c` | `pow(a,b) = exp(b·log(a))` | общая степень из двух готовых функций |

Правила те же: чистый C11, строгая сборка, эталон — реальный запуск.
Сравнение с math.h — в тестовом main, рядом печатаем max |ошибка|.

# 02 — экспонента: Тейлор + сужение диапазона

## Идея

Ряд Тейлора: `e^x = 1 + x + x²/2! + x³/3! + ...` — только умножения и сложения.
Но он хорош лишь при маленьких |x|. Поэтому два шага:

1. **Сужение диапазона:** представим `x = k·ln2 + r`, где k — целое,
   а |r| ≤ ln2/2. Тогда `e^x = 2^k · e^r`. Маленький r считаем рядом,
   а 2^k — сдвигом/умножением.
2. **Ряд для e^r:** суммируем члены, пока очередной не станет меньше
   машинного эпсилон (или фиксированное число членов — сравни подходы).

Трюк: член ряда не пересчитывают заново (нет факториалов!):
`term_новый = term_старый * r / n`.

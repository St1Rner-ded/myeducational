# 01 — корень методом Ньютона

Дробная степень — это корень: a^0.5 = √a. Учимся считать его без math.h.

## Идея

Решаем уравнение `y² = a` итерациями Ньютона (того самого, из диода!):
начинаем с догадки y₀ (например, a или 1), затем:

```
y_новое = (y + a / y) / 2
```

Каждая итерация примерно **удваивает** число верных знаков — попробуй
почувствовать это на распечатке: y после каждого шага.

## Задача

Функция `double own_sqrt (double a)`. В main — тест на значениях
0, 1, 2, 4, 100, 0.25, 1e-6: печать own_sqrt, sqrt из math.h, разница.

Вопросы для размышления: сколько итераций реально нужно (5? 50?)?
Что будет при a = 0? При отрицательном a?

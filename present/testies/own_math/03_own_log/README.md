# 03 — логарифм: мантисса и ряд

## Идея

double внутри: `x = m · 2^e`, где m ∈ [1, 2). Значит:

```
ln(x) = ln(m) + e·ln(2)
```

e·ln(2) — просто умножение. Осталось ln(m) на маленьком диапазоне [1, 2).
Для него удобный ряд через подстановку `z = (m−1)/(m+1)`:

```
ln(m) = 2·(z + z³/3 + z⁵/5 + z⁷/7 + ...)
```

|z| ≤ 1/3 при m ∈ [1,2) — ряд сходится быстро. Члены — снова цепочкой:
`term *= z·z`, знаменатель растёт на 2.

Как достать m и e из double? Вариант А: умножением/делением на 2 в цикле
(просто и честно). Вариант Б: через битовое представление (union) — позже,
если захочется.

# 04 — общая степень: exp и log в связке

## Идея

Любая вещественная степень собирается из двух готовых функций:

```
a^b = exp(b · ln(a))
```

Бинарное quick_pow (из olimp/part2) работает для целых b — оно быстрее
и точнее, поэтому для целых показателей оставляем его. Здесь — общий случай:
дробные, отрицательные, иррациональные показатели.

## Задача

`double own_pow (double a, double b)` через own_exp/own_log.
Тест: (2, 0.5) — это √2, сверка с own_sqrt!; (2, 10); (9, 0.5);
(2, −1); (10, 0.30103) ≈ 2 (log10!). Печать own_pow, pow из math.h, ошибка.

Вопросы: что при a = 0? При a < 0 и дробном b? Почему own_pow(2, 10)
может проиграть quick_pow по точности?

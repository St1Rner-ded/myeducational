# circuitC — дорога к своему симулятору схем на C11

Долгая цель: аналог [circuitjs](https://github.com/pfalstad/circuitjs1) на чистом C —
тот же численный движок (MNA + шаг по времени), но быстрее и с контролем точности.

Идём этапами, каждый этап — своя папка с файлом-задачей, как в `olimp/`.
Этап считается пройденным, когда файл собирается строгими флагами и выход
сходится с эталоном (Python или аналитика).

## Этапы

| # | Папка | Тема | Что получаем на выходе |
|---|---|---|---|
| 01 | `01_dynamic_memory` | `malloc`/`free`, динамический массив, односвязный список | умение держать структуры данных, размер которых неизвестен заранее — будущие «список узлов» и «список элементов» ✅ 2026-11-06 |
| 02 | `02_matrix_gauss` | матрица как структура (указатель + размеры), метод Гаусса с выбором главного элемента | солвер `Ax = b` — сердце MNA ✅ 2026-11-06 |
| 03 | `03_rc_solver` | MNA на матрице 3×3: источник, резистор, конденсатор; дискретизация по методу трапеций | микро-симулятор RC-цепочки: текстовая осциллограмма напряжения на конденсаторе, эталон — аналитическая формула заряда ✅ 2026-11-10 |
| 04 | `04_nonlinear` | диод (модель Шокли), итерации Ньютона–Рафсона | солвер схем с нелинейным элементом |
| 05 | `05_netlist` | парсер списка соединений (netlist) из stdin, автоматическая сборка матрицы MNA | полноценный мини-движок: схема описывается текстом, движок сам строит и решает систему |

Дальше (за горизонтом): адаптивный шаг времени, разреженные матрицы,
свой формат точности там, где `double` мало.

## Правила игры

Те же, что везде в `present/`: чистый C11, строгая сборка `-Werror`,
ввод из stdin, ноль магии — каждая строка понятна. Агент не пишет решение:
он задаёт наводящие вопросы и проверяет результат.

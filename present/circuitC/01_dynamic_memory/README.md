# Этап 01 — динамическая память

До сих пор все массивы были статическими: размер известен на этапе компиляции
(`int a[1000]`). Симулятор заранее не знает, сколько в схеме узлов и элементов,
поэтому учимся брать память в рантайме.

## Что освоить

- `malloc` / `calloc` / `realloc` / `free` из `<stdlib.h>`.
- Проверка результата `malloc` на `NULL`.
- Утечки: каждый `malloc` должен встретить свой `free`. Контроль — ASan
  (рабочая сборка с `-fsanitize=address` сама рапортует об утечках).

## Задача-пропуск

**Динамический массив с доращиванием**: читать из stdin произвольное количество
целых чисел (до EOF), складывая их в массив, который начинается с capacity 8
и удваивается через `realloc`, когда заполнен. В конце — вывести количество,
сумму и финальный capacity.

Критерий готовности: строгая сборка чистая, ASan молчит (ни ошибок, ни утечек)
на входе из 0, 1, 8, 9 и 100000 чисел.

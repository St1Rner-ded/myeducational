# Этап 05 — netlist: схема текстом

До этого схема была зашита в коде. Настоящий движок получает описание схемы
снаружи — список соединений (netlist), как в SPICE. Это финальный шаг
к «своему Фалстаду» на уровне движка.

## Что освоить

- Парсинг строк: `R1 1 2 1000` — элемент, узел, узел, значение.
- Нумерация узлов в неизвестные системы (узел 0 — земля, не считается).
- Автоматическая сборка матрицы MNA по списку элементов любого размера
  (динамическая память этапа 01 + солвер этапа 02).
- Опционально: подключить диод этапа 04.

## Задача-пропуск

Вход из stdin: строки netlist (`R`, `C`, `V`, `D`), последняя строка —
`dt tmax`. Движок сам строит и решает систему, печатает напряжения всех
узлов на каждом шаге времени.

Критерий готовности: RC-цепочка и схема с диодом из прошлых этапов,
поданные как netlist, дают те же результаты, что и зашитые версии.

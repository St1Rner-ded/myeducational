# Этап 04 — нелинейность: диод и Ньютон–Рафсон

Линейные элементы решаются за один проход Гаусса. Диод подчиняется
экспоненте (уравнение Шокли), и система перестаёт быть линейной —
её решают итерациями.

## Что освоить

- Метод Ньютона–Рафсона: линеаризация нелинейного элемента в текущей
  рабочей точке, решение линейной системы, обновление точки — до сходимости.
- Диод как «проводимость + источник тока», пересчитываемые на каждой итерации.
- Критерий сходимости и защита от расходимости (лимит итераций).

## Задача-пропуск

Схема: источник → резистор → диод на землю. Вход: `E R Is n dt tmax`.
Найти установившееся напряжение на диоде.

Критерий готовности: результат совпадает с решением уравнения
`E − U = R·Is·(e^(U/(n·Vt)) − 1)` из Python (`scipy.optimize.brentq`)
на нескольких наборах параметров.

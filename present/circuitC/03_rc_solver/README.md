# Этап 03 — микро-симулятор RC-цепочки

Первый настоящий симулятор. Схема жёстко зашита в коде: источник напряжения,
резистор, конденсатор. Узлов заранее известное количество — матрица маленькая,
но собирается она уже по правилам MNA (модифицированный узловой анализ),
как у больших.

## Что освоить

- MNA: узлы схемы → неизвестные напряжения; каждый элемент «штампует»
  свой вклад в матрицу проводимостей и вектор правой части.
- Дискретизация: конденсатор на шаге `dt` заменяется эквивалентом
  (проводимость + источник тока) по методу трапеций.
- Цикл по времени: собрать матрицу → решить (этап 02) → вывести точку →
  обновить состояние конденсатора.

## Задача-пропуск

Вход из stdin: `E R C dt tmax`. Симулировать заряд конденсатора от 0 В,
печатать `t Uc` на каждом шаге.

Критерий готовности: кривая совпадает с аналитикой `Uc(t) = E·(1 − e^(−t/RC))`
с точностью, растущей при уменьшении `dt` (проверить на двух разных `dt`).

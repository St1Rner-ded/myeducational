# Этап 02 — матрицы и метод Гаусса

Сердце любого симулятора схем — решение системы линейных уравнений `Ax = b`
на каждом шаге времени. Здесь строим это с нуля.

## Что освоить

- Структура `матрица`: `double *data` (динамическая, этап 01) + `rows`/`cols`.
- Индексация плоского массива как двумерного: `data[i * cols + j]`.
- Метод Гаусса с частичным выбором главного элемента (partial pivoting):
  без него ноль на диагонали ломает всё решение.
- Почему `double` и где теряется точность.

## Задача-пропуск

Читать из stdin размер `n`, затем матрицу `A` (n×n) и вектор `b`.
Решить `Ax = b` методом Гаусса, вывести `x` с шестью знаками после точки.

Критерий готовности: на системе с известным аналитическим ответом
(например, матрица Гильберта 5×5 с правой частью из единиц) выход совпадает
с эталоном из Python (`numpy.linalg.solve`) до 6-го знака.

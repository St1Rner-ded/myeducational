Как пользоваться:

1. Распакуй этот архив В КОРЕНЬ своего репозитория myeducational —
   появится папка solutions/ с заготовками задач.
2. Открой solutions/L0/L0-T1.cpp, допиши код только между маркерами
   SOLUTION START / SOLUTION END. Тесты в main() не меняй.
3. Скомпилируй и запусти:
     g++ -std=c++20 -Wall -Wextra -Wpedantic -Wshadow -g -fsanitize=address,undefined L0-T1.cpp -o t && ./t
   (для .c файлов: gcc -std=c11 ... L1-T1.c -o t -lm && ./t)
   Ожидание: ALL TESTS PASSED
4. Заполни solutions/answers_A.md (часть A и часть C из диагностики).
5. git add solutions && git commit -m "diagnostika" && git push
6. Напиши в чат «проверь диагностику» — я скомпилирую всё у себя
   со строгими флагами и санитайзерами и пришлю разбор.

Решать ВСЁ не нужно: иди сверху вниз и остановись там, где начинаешь плавать.

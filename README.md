# myeducational — лаборатория C11

Личный репозиторий для изучения чистого **C11** через эксперименты: указатели и память,
массивы и строки, битовые операции, структуры данных, алгоритмы и переносимость.

Долгая цель — свой симулятор электронных схем на C (аналог circuitjs): трек
**[circuitC](present/circuitC/README.md)** ведёт от динамической памяти и метода Гаусса
к MNA, нелинейным элементам и разбору netlist.

Это не набор эталонных решений и не линейный курс. Главный вопрос здесь — не только
«работает ли программа?», но и «что именно гарантирует язык, что зависит от платформы
и как это проверить запуском?».

## С чего начать

- **[Справочник по C](SPRAVOCHNIK.md)** — правила языка, платформенные различия,
  инструменты и каталог реальных ошибок. Это основная точка входа.
- **[Тесты на указатели](present/not_olimp/tests/README.md)** — шесть небольших
  программ, которые можно читать, запускать и проверять по порядку.
- **[Правила репозитория](AGENTS.md)** — стиль кода, строгие флаги сборки и текущий фокус.

## Быстрый запуск

Основная среда — **WSL2 Debian, GCC, x86-64 Linux**.

Прогнать серию тестов на указатели:

```bash
cd present/not_olimp/tests
./run.sh
```

Собрать отдельный эксперимент с предупреждениями и санитайзерами:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wsign-conversion \
    -Wformat=2 -g -fsanitize=address,undefined file.c -o /tmp/t && /tmp/t
```

Перед коммитом используется строгая сборка с `-Werror`. Полные правила и варианты для
Windows/MinGW описаны в [AGENTS.md](AGENTS.md) и
[§7 справочника](SPRAVOCHNIK.md#7-компиляция-и-инструменты).

## Как устроен репозиторий

| Каталог | Назначение |
|---|---|
| `present/not_olimp/` | Эксперименты с памятью, указателями и структурами данных |
| `present/circuitC/` | Трек к своему симулятору схем: память → Гаусс → RC-солвер → нелинейность → netlist |
| `present/olimp/` | Алгоритмические задачи и вспомогательные стенды |
| `present/testies/` | Короткие изолированные проверки |
| `archive/theory/` | Архивные конспекты и подробные разборы |
| `archive/reviews/` | Прошлые код-ревью |
| `archive/solutions/` | Старые решения и заглушки для возможного переноса в C11 |
| `archive/scratch/` | Черновики и эксперименты прежних итераций |

`archive/` — **архив**, а не образец текущего стиля. В частности, там остаются C++-материалы;
актуальный трек репозитория — чистый C11.

## Принцип работы

- Числа и утверждения о поведении по возможности подтверждаются реальным запуском.
- Гарантии стандарта отделяются от свойств конкретного компилятора и платформы.
- Новый код собирается без предупреждений и проверяется санитайзерами там, где они доступны.
- Программы для задач читают вход через стандартный поток, а генераторы используются
  только как отдельные стенды.
- Ошибка, разобранная и воспроизведённая на практике, может стать записью в каталоге
  [§9 справочника](SPRAVOCHNIK.md#9-каталог-частых-ошибок).

# myeducational — Практикум по C (C11)

Личный учебный репозиторий по системному и алгоритмическому программированию на чистом **C (стандарт C11)**.
Основной упор — низкоуровневая работа с памятью, указатели, битовые операции, базовые структуры данных своими руками, переносимость кода (`x86-64 Linux` ↔ микроконтроллеры `AVR / Arduino`) и защита от неопределённого поведения (UB).

---

## 📖 Живой справочник — [`SPRAVOCHNIK.md`](SPRAVOCHNIK.md)

В корне репозитория ведётся единый справочник **[`SPRAVOCHNIK.md`](SPRAVOCHNIK.md)**, который пополняется по мере прохождения тем и разбора реальных ошибок:

* размеры и диапазоны типов (`<stdint.h>`, `<limits.h>`), проверенные реальными запусками;
* форматированный ввод-вывод (`printf` / `scanf` / `fgets`) и безопасная работа с буферами;
* указатели, массивы, строки и управление динамической памятью (`malloc` / `realloc` / `free`);
* битовые операции, маски, сдвиги, `two's complement`, порядок байтов (`endianness`);
* выравнивание структур (`sizeof`, `offsetof`, padding);
* **§9 Каталог частых ошибок** — личная коллекция граблей, пойманных на практике.

## ⚙️ Среда и стандарты компиляции

* **ОС и окружение:** Windows 11 + WSL2 (`Debian GNU/Linux`), VS Code.
* **Стандарт языка:** чистый `C11` (`-std=c11`).
* **Главное правило сборки:** ноль предупреждений компилятора при максимальной строгости и включённых санитайзерах.

### Рабочие флаги (`gcc`)

Для повседневной сборки и отладки с `AddressSanitizer` и `UndefinedBehaviorSanitizer`:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wsign-conversion -Wformat=2 -g \
    -fsanitize=address,undefined file.c -o /tmp/t && /tmp/t
```

Для строгой проверки перед коммитом (`-Werror` превращает любое предупреждение в ошибку):

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wsign-conversion -Wformat=2 -Werror \
    file.c -o /tmp/t && /tmp/t
```

### Удобные алиасы для `~/.bashrc` в WSL

```bash
alias cc='gcc -std=c11 -Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wsign-conversion -Wformat=2 -g -fsanitize=address,undefined'
alias ccs='gcc -std=c11 -Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wsign-conversion -Wformat=2 -Werror'
```

> 💡 **Гигиена Git в Linux:** скомпилированные ELF-бинарники не должны попадать в `git status`.
> Собирай во временную директорию `-o /tmp/t` (предпочтительно), либо в файл с расширением,
> который уже есть в `.gitignore`: `t` / `*.out` / `*.o` / `*.exe`.
